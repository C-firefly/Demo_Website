# ডাক্তার ওয়েবসাইট – স্ট্যাটিক ইন্টারেক্টিভ ডেমো

কোনো ব্যাকএন্ড, ডাটাবেস বা ইনস্টলেশন লাগে না। সব ডেটা নমুনা এবং শুধু মেমোরিতে থাকে – রিফ্রেশ করলে আগের অবস্থায় ফিরে যায়
(localStorage / cookie / IndexedDB ব্যবহার করা হয়নি)।

## কীভাবে খুলবেন
1. **সবচেয়ে সহজ:** `index.html` ফাইলটি ব্রাউজারে ওপেন করুন (ডাবল-ক্লিক)। Bootstrap/ফন্ট CDN থেকে আসে, তাই ইন্টারনেট লাগবে।
2. **ফোনে দেখতে (বিনামূল্যে, লাইভ):** GitHub-এ নতুন রিপো বানিয়ে সব ফাইল আপলোড করুন → *Settings → Pages → Branch: main / root → Save*।
   কিছুক্ষণ পর `https://আপনার-নাম.github.io/রিপো-নাম/` লিংকে ফোনের ব্রাউজারে খুলুন।
3. Termux: `pkg install python && python -m http.server 8080` চালিয়ে ব্রাউজারে `http://localhost:8080` খুলুন।

## কীভাবে ঘুরে দেখবেন
- নেভিগেশনের **“ডেমো প্যানেল”** মেনু থেকে রোগী ড্যাশবোর্ড ও অ্যাডমিন প্যানেলে যান (লগইন পাতায় “দ্রুত ডেমো” বাটনও আছে)।
- বুকিং: অ্যাপয়েন্টমেন্ট → ৫ ধাপ → নিশ্চিত করুন।
- শপ: পণ্য খুঁজুন/ফিল্টার করুন → কার্ট → চেকআউট → পেমেন্ট অপশন (শুধু ক্যাশ অন ডেলিভারি ও ডেমো পেমেন্ট কাজ করে)।
- অনুদান, যোগাযোগ ফর্ম পাঠালে অ্যাডমিন প্যানেলের তালিকায় (রিফ্রেশ না করা পর্যন্ত) দেখা যাবে।

## ফাইল কাঠামো
- `index.html` – একটি পাতার অ্যাপ; সব স্ক্রিন `#/route` দিয়ে চলে (যেমন `#/shop`, `#/p/dashboard`, `#/a/products`)।
- `assets/js/sample-data.js` – নমুনা তথ্য (এখানে নাম, দাম, পণ্য বদলান)।
- `assets/js/app.js` – সব পাতা ও ইন্টারঅ্যাকশন। `assets/css/style.css` – সব স্টাইল।
- `pages/`, `patient/`, `admin/` – আপনার চাওয়া ফাইল-পাথগুলো; প্রতিটি `index.html`-এর সংশ্লিষ্ট স্ক্রিনে নিয়ে যায়।
  (কুকি/স্টোরেজ ছাড়া মাল্টি-পেজ সাইটে কার্ট ধরে রাখা যায় না, তাই একটি পাতার কাঠামো ব্যবহার করা হয়েছে।)
- ছবির বদলে রঙিন আইকন-প্লেসহোল্ডার ব্যবহৃত হয়েছে, তাই কোনো ছবি ভাঙে না।
